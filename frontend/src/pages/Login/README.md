# Tela de Login 🔐

Este projeto é uma tela de login simples desenvolvida para fins de estudo e prática de HTML, CSS e JavaScript.  
O objetivo é simular o processo de autenticação de usuários em uma interface amigável e responsiva.

## 🚀 Funcionalidades
- Campo para **usuário** e **senha**
- Botão de **login**
- Validação básica dos campos
- Layout responsivo para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas
- **HTML5** para estrutura da página
- **CSS3** para estilização e responsividade
- **JavaScript** para validação e interatividade
